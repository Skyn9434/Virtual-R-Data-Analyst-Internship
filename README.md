# Virtual R Data Analyst Internship — Titanic Case Study

## Dataset
Titanic passenger dataset (891 rows, 12 original fields), publicly available from:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

## Deliverables
- Week_1_Data_Cleaning_Report.docx
- Week_2_Data_Visualization_Report.docx
- Week_3_Statistical_Modeling_Report.docx
- r_scripts/week1_cleaning.R
- r_scripts/week2_visualization.R
- r_scripts/week3_modeling.R
- data/titanic_raw.csv
- data/titanic_cleaned.csv

## Main methods
1. Missing-value treatment
2. IQR outlier detection and Fare capping
3. Feature engineering
4. Descriptive statistics and visualization
5. Chi-square hypothesis test
6. Logistic regression classification
7. Accuracy, precision, recall, F1 and ROC-AUC evaluation

## R packages
Week 1: dplyr
Week 2: dplyr, ggplot2, scales
Week 3: dplyr

Run the scripts in order: Week 1 → Week 2 → Week 3.
